# 🥚 Яйцерез

Сам нарезает исходники для видео. Перетащите видео с камеры и запись с микрофона — Яйцерез:

1. **синхронизирует звук** микрофона со звуком камеры (взаимная корреляция, точность до миллисекунды, хлопушка не нужна);
2. **распознаёт речь** локально на видеокарте (Whisper large-v3-turbo, русский и английский);
3. **отсеивает неудачные дубли**: оборванные фразы не попадают в монтаж; если мысль переговорена заново —
   даже другими словами или целым абзацем — остаётся последний вариант, остальные уходят в «запасные»;
4. **режет по звуковой волне**: на каждой склейке одинаковая пауза — от «свободно» до «встык» и с наездом;
   вдохи и выдохи на склейках вырезаются, глухие согласные остаются;
5. вырезает **отдельные слова**: мат, «э-э», «м-м» и свой список — фраза при этом остаётся;
6. показывает **предпросмотр**: плеер, таймлайн с зумом, текст как в Spotify (текущая фраза и слово подсвечиваются);
   на каждой склейке видно, что там вырезано, — можно вернуть дубль или подрезать край куска по кадрам;
7. **несколько дорожек**: вторая камера, скринкаст — всё синхронизируется по звуку и режется одинаково,
   дорожку можно добавить и после обработки;
8. сохраняет **XML** (Final Cut Pro 7 XML) — открывается в Premiere Pro и DaVinci Resolve:
   V1 — видео, V2+ — дополнительные дорожки, A1 — микрофон, A2 — звук камеры.

## Установка

Скачайте **[Yaitserez-Setup.exe](https://github.com/brlk33/Yaitserez/raw/main/Yaitserez-Setup.exe)** и запустите.
Установщик сам скачает Python, библиотеки и ffmpeg (около 2,5 ГБ, 5–15 минут, нужен интернет)
и создаст ярлык «Яйцерез» на рабочем столе.

Требования: Windows 10/11 64-бит. Видеокарта NVIDIA рекомендуется — час записи разбирается за 2–3 минуты.

Если установлен [VoiceType](https://github.com/brlk33/Voice-Type), Яйцерез возьмёт его модели
(Whisper и Qwen для смыслового поиска дублей) и ничего лишнего не скачает. Иначе модель распознавания
(~1,5 ГБ) скачается при первом запуске.

## Из исходников

```bat
install.bat
```

`install.bat` ставит Python 3.12 через [uv](https://github.com/astral-sh/uv), библиотеки из `requirements.txt`,
ffmpeg, собирает `Yaitserez.exe` с иконкой и ярлыки. Установщик собирается из `installer/installer.nsi` (NSIS 3).

## Где что лежит

| Что | Где |
|---|---|
| Кеш распознавания, превью, настройки | папка `data` рядом с программой (или `YAITSEREZ_HOME`) |
| ffmpeg | `tools/ffmpeg` |
| Модели | у VoiceType, если он установлен, иначе `data/models` |

Кеш можно очистить в «Настройках» программы — он пересоздастся.
